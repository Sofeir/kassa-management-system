# Система управления кассами

Центральный сайт, через который организации-клиенты управляют своими кассами ASOFT.
Структура: организация → подразделение → столовая → касса.

Сейчас это тестовая версия на чистом HTML/CSS/JS. Данные хранятся в `localStorage` браузера, сервера и базы нет.
Касса (ASOFT POS) живёт в отдельном репозитории.

## Что есть

- Обзор: выручка, чеки, связь касс, срок ФН, сводка журнала безопасности.
- Структура: организации, подразделения, столовые, кассы.
- Меню: на организацию, подразделение или столовую. Ближний уровень побеждает.
- Пользователи и профили прав.
- Кассы: оборудование, подключение, ФН.
- Шаблоны рабочих мест: настройки одной кассы применяются к столовой или к выбранным кассам. Номер ФН, срок ФН и IP не переносятся.
- Отчёты с выгрузкой в CSV.
- Журнал безопасности: удаление из чека, отмена, возврат, скидка вручную, изъятие наличных, ящик без продажи, неверный PIN.
- Журнал изменений.

## Сайт

Открытая версия: https://sofeir.github.io/kassa-management-system/
Публикуется сама через GitHub Actions (`.github/workflows/pages.yml`) при каждом push в `main`.

## Запуск

```
npm start
```

Откройте http://localhost:5190. Кнопка «Сбросить демо-данные» в меню возвращает начальные данные.

## Файлы

- `index.html`, `css/manager.css`, `js/store.js` (данные и расчёты), `js/app.js` (интерфейс).
- `serve.js`: простой статический сервер.
- `docs/site-variants.html`: варианты интерфейса, из которых выбран текущий.
